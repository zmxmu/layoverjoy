## 6. `~/.zshrc` 改动说明（已执行，未删除任何原有配置）

原本 `~/.zshrc` 已有 `ANDROID_HOME/ANDROID_SDK_ROOT/PATH`（platform-tools、emulator、cmdline-tools），`java`、`adb`、`docker` 在新终端**本来就可用**（实测 `zsh -lic`）。唯一缺口是登录 shell 里 `JAVA_HOME` 为空（Gradle 依赖 PATH 上的 `java` 才能找到 JDK 17）。本次仅在文件末尾**追加**一段带守卫的配置（已有 `JAVA_HOME` 时不覆盖）：

```zsh
# ---- LayoverJoy handoff: ensure JDK 17 for Gradle (guarded, appended 2026-08-30) ----
if [ -z "$JAVA_HOME" ] && [ -x /usr/libexec/java_home ]; then
  export JAVA_HOME="$(/usr/libexec/java_home -v 17 2>/dev/null)"
fi
```

回滚：删掉这 4 行即可（`grep -n "LayoverJoy handoff" ~/.zshrc` 定位）。原文件中 Devin / CodeBuddy / `.local/bin/env` 等条目**未改动**。
